# duneawakening-countdown
Countdown webpage for the launch of dune awakening

To use, open background.html in a browser of your choice. To add a custom image, copy that to this directory and either rename it dune_bg.png, replacing the existing image, or modify background.html to add the name of your image to this line:
background: url('dune_bg.png') no-repeat center center fixed;

The current version only shows the time expected to launch the Advanced Release of the game (June 5, 2025). Perhaps in a future edition, there will be a way to switch between that and the normal release date (June 10, 2025).

The code and times were mostly generated by chatgpt (with some minor debugging/changes by me). I make no other claims of functionality :). I go by eindinbloch in most games, so feel free to ping in the Dune Awakening discord if you have questions about it.
